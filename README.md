# Universität Hildesheim · Technikdidaktik

Lernplattformen zu Lehrveranstaltungen von Daniel Beyrodt am Institut für Technik der Universität Hildesheim.

- **Technikdidaktisches Kolloquium (WiSe 2026/27):** `technikdidaktisches-kolloquium/` – drei Termine nach dem Kursaufbau WiSe 2023/24: Präsentation mit den Aufgaben (PPTX/PDF), Aufgabenpakete mit Schreibaufträgen, Abschluss-Check und Export.

Die Plattform läuft komplett im Browser; Eingaben bleiben im Browser der Nutzenden.
